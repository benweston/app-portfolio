# App - Portfolio ([benweston.site](https://benweston.site/))

<div align="justify">

> The personal engineering hub, technical writing showcase, and systems architecture sandbox for [benweston.site](https://benweston.site/).  Focused on enterprise Linux operations, developer productivity tooling, and Google Cloud infrastructure — engineered with [Astro 5](https://astro.build/) for zero-JS runtime performance, deployed globally across Google's Edge CDN via [Firebase Multisite](https://firebase.google.com/docs/hosting/multisites), and maintained through a state-of-the-art agentic pairing harness powered by Google Antigravity with automated Trunk-Based CI/CD.   

</div>
